# ADR 0001: Выбор MCP SDK для Go

Статус: принято (2026-10-05)

## Контекст

Портируем vikunja-mcp (Python, FastMCP) на Go. Нужен stdio-сервер с 81 namespaced-инструментом.

Кандидаты:

1. **Официальный modelcontextprotocol/go-sdk** (v1.8.0 на момент решения)
2. mark3labs/mcp-go (зрелый community SDK)

## Решение

Официальный SDK.

## Обоснование

- поддерживается самим проектом MCP — API следует спецификации, не отстаёт от неё;
- v1.8.0: API стабилен (v1.x), совместим с текущими клиентами;
- схемно-ориентированный подход (`mcp.NewServer` + `AddTool` со схемой из Go-типов) ложится на задачу кодогенерации схем из struct-тегов — главную трудоёмкость порта;
- mark3labs/mcp-go добавляет собственный слой абстракций и варианты выбора API, которые в v1.x официального SDK уже решены.

Риски: официальный SDK младше по возрасту; при недостающей функциональности — вернуться к сравнению повторно.
